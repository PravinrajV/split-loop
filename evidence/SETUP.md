# QNX/QEMU experiment setup

Not a medical device; not certified; not a patient-treatment product.

- Host: shared Debian 13 box; not an officially supported SDP host. No CPU pinning, exclusive host or hardware real-time claim. Other agents may be active.
- QEMU: /usr/bin/qemu-system-x86_64 10.0.13, TCG (-accel tcg -cpu max), one vCPU, 512 MiB RAM. KVM is not used. Exact argv is captured beside each log.
- Image: images/split-loop, generated by the installed licensed /home/box/qnx800 mkqnximage. This is a small disposable disk and IFS, not the QSTI image. No QSTI raw member was extracted.
- QNX 8.0.0 exact kernel/build string is in each serial boot log. Security policy is compiled and loaded with --secpol=secure; secpolgenerate is absent from the enforcing boot.
- Plant: unit inertia, viscous friction 1.2, feedforward compensation and sensor-feedback correction; fixed 10 ms integration. A jerk-feasible velocity braking envelope prevents feedback from exceeding each run's velocity cap. Truth, deterministic small sinusoidal sensor noise, and presentation are separate fields.
- Baseline reference remains frozen: Y180, then X390, then Y250; scalar v80, a200, j600. The implementation uses the jerk-limited (seven-phase) trapezoid implied by the finite jerk cap. No diagonal cuts.
- The native scalar profiler uses a checked direct slot-to-dock path, v140, a350, j1400. Axis derivatives are synchronized by scalar path length. This is not a trained model and the UI does not use an AI label.
- Fallback starts from current truth q/v/a and checks bounded candidate quintic HOME recovery profiles before execution. The joint manager independently constrains second-order acceleration, jerk and swept keep-outs. Tests are finite simulator tests, not formal verification or continuous physical instrument validation.
- Clock: actual CLOCK_MONOTONIC period timestamps. Start is the first period with center >2 mm from the start slot; stop is the first of ten consecutive qualifying dock periods (8 mm, each-axis speed <=5 and acceleration <=50). A HOME/FAIL outcome has no successful cycle time.
- Controller uses absolute sleeps and SCHED_FIFO priority 40. Advisor uses FIFO priority 10. Managers use QNX message-driven priority inheritance. Isolated mode takes at most three shared snapshot attempts and never MsgSends the advisor; joint IPC is synchronous. Naive mode calls MsgSend to the advisor with a two-second catastrophic timeout; the watchdog normally restarts a hung advisor around the 200 ms heartbeat threshold.
- Watchdog observes a monotonic receive heartbeat maintained by /dev/advice, not the proposal timestamp (a deliberately stale proposal must not masquerade as a crash). Only advisor processes are restarted. Teardown of a completed/reset disposable run is separate from watchdog recovery.
- Raw samples are appended by control into 4096 fixed records; excess records are dropped. Control does not print telemetry. A separate lower-priority process reads the latest completed record at 10 Hz and can block only itself on serial output; skipped presentation frames are intentionally lossy. Raw controller samples are exported after completion.
- Lateness = actual wake minus nominal deadline. Command completion = actual wake through final joint read, including a naive synchronous ask. A missed period means lateness >=10 ms OR command completion beyond the next nominal deadline. Both conditions count at most once per sample.
- Catch-up: after a delayed wake, nominal deadlines continue in 10 ms increments. The discrete plant advances one 10 ms model step per executed control iteration; a delayed naive ask is therefore visible in the real-time clock/lateness samples, not erased by inventing model elapsed time. This is not a physical-time hardware model during an overrun.
- Percentiles use nearest-rank p50/p95/p99/max, not averages or invented timing values. Max observed is not WCET. Advisory ages of -1 mean no applicable advice and are omitted from age percentiles.
- The A/B pair is one preset repeated workload in one image, not a statistical guarantee. All matrix cases and all raw samples remain available, including incidental misses outside the selected hang comparison.
- Earlier logs are retained, including development generator warnings, an early fstat-observation failure, and a feedback velocity overshoot found during review. The latter was fixed by enforcing the already-frozen velocity cap, not by changing the baseline reference; baseline self-checks were rerun before the final comparison. Use acceptance.json as the final indexed evidence, not an earlier file with “final” in its name.
